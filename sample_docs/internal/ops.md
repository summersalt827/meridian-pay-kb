# 资金账户操作手册与合规要求（机密 · 仅 admin）

> 本页含资金操作 SOP 与监管合规要求，属 L3 机密。

## 一、每日结算与对账 SOP

- **结算时间点**：每日 18:00（新加坡时间）为资金账户当日结算截止点，18:00 之后的交易计入次日。
- 结算流程：资金账户交易汇总 → 与清算行对账 → 差异挂账 → 出具日终报表。
- 资金账户的日终余额须与清算行回单一致，差异未平不得关闭当日结算。
- 对账差异超过 5,000 SGD 须在 **30 分钟内** 上报资金主管。
- 日终报表在 20:00 前推送至资金组邮件组，并归档到合规库留存 7 年。
- 结算完成后，系统为每个资金账户生成结算凭证，凭证号须写入日终报表。
- 结算异常时，资金账户当日结算可延后至次日 10:00，但须在资金台账登记延后原因。
- 结算流程实行双人复核：一人执行结算，一人复核资金账户余额与清算行回单。
- 月末最后一天加做一次全量对账，由财务负责人签字确认。

## 二、备用金（float）审批权限

- 单笔 50,000 SGD 以内：资金主管审批即可动用。
- 50,000 - 200,000 SGD：财务负责人审批。
- 超过 200,000 SGD：须 CEO 与合规负责人双签。
- 所有备用金动用须在资金台账登记并留存凭证，禁止口头授权。
- 备用金缺口超过 100,000 SGD 时，需在当日向 CFO 报备头寸安排。

## 三、合规要求：MAS 与 PDPA 审计留痕

- 所有涉及客户数据的操作必须可追溯：**操作人、时间、对象、原因** 四要素齐备。
- 审计留痕保存 **7 年**，MAS 现场检查时需在 3 个工作日内提供完整链路。
- PDPA 要求：个人信息调取须有书面授权，禁止导出到个人终端或私人网盘。
- 每季度执行一次权限复核，离职账号 24 小时内冻结，外包账号到期自动失效。
- 监管口径：任何一次越权访问尝试都要留痕并触发告警，不得以任何理由删除记录。

## 四、数据分级政策

- L1 公开：产品说明、对外宣传材料、官网定价页。
- L2 内部：路线图、组织架构、行政与人事制度。
- L3 机密：身份资料（KYC 档案）、交易流水、结算底稿、合同原件。
- L3 数据默认仅 admin 可见，跨级调阅需合规负责人书面同意并留痕。
- 分级标签写入文档头部，摄入知识库时自动继承为检索权限。

## 五、故障处理

- 先止损再定位：优先切换备用清算通道，保留现场日志。
- 一级故障（影响出款）须在 1 小时内上报，24 小时内提交复盘报告。
- 与清算行沟通统一由资金主管对口，禁止多人并行对接。
