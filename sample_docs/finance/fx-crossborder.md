# 跨境付款与外汇政策（财务部）

> 适用范围：财务部、销售部。密级 2。

## 一、币种与支付路径

- 支持币种：SGD / USD / EUR / GBP / HKD
- 大额付款默认走 SWIFT 网络；小额高频付款走本地清算通道
- 到账时效：本地清算当日，SWIFT 1–3 个工作日

## 二、汇率定价

- 汇率加点按客户用量档位定价，月付款量越高加点越低
- 汇率锁定最长 48 小时，锁定期间价格不受市场波动影响
- 大客户可申请定制汇率方案，由财务部与销售部联合审批

## 三、合规联动

- 单笔付款 ≥ S$30,000 触发反洗钱预审，联动合规团队
- 新增收款国家（非主流市场）须先完成合规准入评估
- 收款方名称与制裁名单实时比对，命中即拦截并上报

## 四、手续费

- 本地转账免手续费；跨境付款按金额阶梯计费
- 月付款量 ≥ S$50 万的企业客户享专属费率
