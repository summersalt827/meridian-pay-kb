# 内部行政 FAQ（全员可见）

> 适用范围：全体同事。本页内容不含任何业务机密，可自由转发。

## 一、报销流程：提交时限与出款时间

- **报销流程**：提交 → 直属主管审核 → 财务复核 → 出款，四步全程在 OA 留痕。
- 报销单在 OA 系统「费用」模块提交，需上传发票原件照片与一句业务说明。
- 提交时限：费用产生后 **30 天内** 必须提交；逾期需直属主管书面说明原因。
- 审核链路：直属主管 → 财务复核 → 出款。单笔超过 2,000 SGD 需财务负责人复核。
- 出款时间：每周三、周五各出款一次，审核通过后 3 个工作日内到账。
- 常见退回原因：发票抬头不符、缺少业务说明、同一笔费用重复提交。

## 二、休假政策

- 带薪年假 **18 天/年**，入职当年按剩余月份折算，次年 1 月 1 日重置。
- 病假需提供诊所或医院证明，全年 14 天以内不影响季度考核。
- 调休需在当季度内用完，跨季度自动清零，不可折现。
- 请假 3 天以上须提前 5 个工作日在 OA 提交，并与直属主管口头对齐交接人。
- 法定公共假日按新加坡人力部公告执行，跨境团队按所在地区日历。

## 三、办公用品与设备申请

- 常用耗材（文具、线缆、转接头、充电器）在行政台自助取用，无需申请。
- 需要新增显示器、键盘、升降桌等办公配件，在 OA「行政服务」提交申领单。
- 申领单由行政团队在 **2 个工作日内** 处理，费用计入所属部门预算。
- 单价超过 500 SGD 的配件需部门负责人同意，并在申领单备注用途。

## 五、找谁

- 报销单进度：在 OA「费用」模块查看当前节点，超过 3 个工作日未动可催办。
- 门禁、工位、快递：行政团队，3 楼前台。
- 电脑、邮箱、软件安装：IT 服务台，helpdesk 提交工单。
- 入职、休假、社保类人事问题：人事自助服务，或发邮件到 people@meridian-pay.com。
- 发票抬头与税务问题：财务共享邮箱 finance@meridian-pay.com。
