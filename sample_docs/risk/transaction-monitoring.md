# 交易监控规则（风控部）

> 适用范围：风控部、合规部。密级 3。

## 一、异常阈值

- 单笔入账金额超过该账户历史月均入账 3 倍 → 转人工复核
- 新开账户 30 天内出现高频小额试刷 → 冻结卡片并外呼确认
- 单日失败交易尝试 ≥ 10 次 → 触发设备风险评分

## 二、频次与时段规则

- 同一商户 1 小时内重复扣款 ≥ 5 次 → 风控拦截并推送人工
- 夜间时段（0:00–6:00）跨境入账 → 延迟入账至次日人工确认
- 连续 3 日交易额逐日翻倍 → 标记为可疑模式

## 三、监控台账

- 每次拦截须记录：时间、金额、规则编号、处置人与处置结果
- 台账每周由风控负责人抽检 10%，抽检结果计入月度报告
