# 客户案例集

> 仅 sales 及以上角色可见。案例数字来自上线后 3 个月的实测口径，可对外引用。

## 案例一：跨境 B2B 贸易商（新加坡，120 人）

- **背景**：从中国与越南采购，转口销往欧美，月均 400+ 笔供应商付款。
- **痛点**：每笔走银行电汇，笔均 3 天到账，财务对账每月占用 6 个人天，汇率损失不可见。
- **方案**：多币种钱包 + 批量付款 + 账单 API 自动核销。
- **结果**：到账时效从 T+3 缩短到 T+1，对账工时下降 70%，换汇成本透明化后节省 1.2 个百分点。
- **可复用话术**：「你们现在每月 400 笔付款，如果每笔快两天，相当于多出 26 天的周转空间。」

## 案例二：区域连锁餐饮（马来西亚，38 家门店）

- **背景**：门店零星采购长期用现金与店长私人卡，票据与对账混乱。
- **痛点**：店长垫付后手工记账，月度核销要跑 5 天，异常支出事后才发现。
- **方案**：每家门店 3 张虚拟商务卡，按门店设额度与商户类别限制。
- **结果**：异常支出下降 45%，月度核销从 5 天压到 1 天，店长不再垫付。
- **可复用话术**：「把每家门店的采购额度提前设好，超额度自动拒付，不需要事后查账。」

## 案例三：SaaS 出海团队（印尼，60 人）

- **背景**：收款以 USD 为主，付款以 SGD 与 IDR 为主，币种错配。
- **痛点**：换汇损失吃掉约 3% 毛利，回款周期长导致季度回款压力大。
- **方案**：USD / SGD / IDR 三币种钱包 + 30 天远期锁汇 + API 自动出款。
- **结果**：上线 3 个月后**回款周期缩短 40%**，换汇成本下降 1.8 个百分点。
- **可复用话术**：「同规模的出海团队，上线三个月把回款周期压了 40%。」

## 案例四：跨境 B2B 设备出口商（深圳，420 人，东南亚扩张）

- **背景**：机械配件出口，月均 450 笔跨境收款，币种 6 种；B 轮融资后 4 个月内新开 2 个东南亚主体。
- **痛点**：三家银行网银分别管理，Excel 手工对账每周约 26 个财务工时，汇率损失不可见，多主体权限混乱。
- **方案**：Enterprise 套餐 + 本地清算通道 + 账单 API 对接自建 ERP + 多账套分级授权。
- **结果**：对账工时从每周 26 小时降到 5 小时（-80%）；换汇成本下降 0.6 个百分点；新增主体复用同一套权限配置，上线周期从 6 周压到 2 周。
- **可复用话术**：「420 人规模、月均 450 笔收款的公司，对账从每周 26 小时降到 5 小时——先补银行短板，再谈替换。」
