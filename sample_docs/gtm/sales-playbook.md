# 销售 SOP：从开场到复盘

> 适用对象：SDR、AE 与销售管理者。仅 sales 及以上角色可见。

## 一、开场白（30 秒版本）

- 锚定痛点：「很多东南亚外贸团队付供应商货款时，银行电汇要 2-3 天才到账，还得跑柜台签字。」
- 一句话定位：我们是给中小企业用的商务卡 + 跨境付款平台，开卡与出款全部在线完成。
- 用提问收尾：「想先了解一下，你们现在给供应商付款是怎么走的，方便吗？」
- 禁忌：不要在开场念产品参数，先让对方讲现状，讲得越多越容易成单。

## 二、需求挖掘提问清单

1. **现状**：现在跨境付款走哪家银行？笔均费率大概几个点？到账要几天？
2. **痛点**：月末对账要花多少人天？有没有因为付款延迟被供应商催过？
3. **影响**：付款慢造成的损失怎么衡量？有没有因此丢过订单？
4. **期望**：如果到账能压到 T+1，对你们的周转压力能缓解多少？
5. **决策**：这类工具通常要财务负责人拍板，贵司谁参与决策？预算周期怎么走？

## 三、演示（Demo）要点

- 按对方行业挑场景演示：贸易商看批量付款，连锁看门店卡，SaaS 看多币种收款。
- 现场开一张虚拟卡，让对方看到「10 秒开卡、额度可限」这一下。
- 演示对账自动化时，用对方真实的月度付款笔数做测算，别用模板数字。
- 总时长控制在 20 分钟内，留 10 分钟回答提问。

## 四、异议处理

| 常见异议 | 应对 |
|---|---|
| 「我们已经用银行了」 | 不替换银行，补银行的短板：多币种换汇与门店卡场景 |
| 「价格太贵」 | 换算成单笔成本与人力成本，对比现有手续费 + 财务工时 |
| 「合规过不了」 | 提供 MAS 持牌资质与尽调材料清单，走合规联合拜访 |
| 「先看看」 | 给沙箱账号，约定一周后回访，明确下一步时间点 |

## 五、赢单 / 丢单复盘

- 赢单复盘：记录触发点（哪个场景让对方决定试用）、决策链条、上线周期。
- 丢单复盘：区分三类原因——无预算、竞品锁定、合规门槛未通过。
- 每单在 CRM 填写复盘表，月度销售例会抽取 3 单做深度复盘。
- 连续两月丢单原因集中在同一类，上升为产品与市场的联合议题。
