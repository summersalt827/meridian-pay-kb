# 信号定义库（Signal Library）

> 仅 sales 及以上角色可见。评分卡（Fit×Timing×Access×Intent）的判定依据。
> 每条信号固定三段式：Definition（定义）/ Why-predicts-fit（成交预示逻辑）/ Hook（首触钩子）。
> 虚构数据，演示用途（honest simulation）。

## S1 融资信号

- **Definition**：企业完成 B 轮及以上融资，或可查证的新一轮融资新闻。
- **Why-predicts-fit**：融资后 2-3 个季度是工具类支出扩张窗口；扩团队与扩市场的预算同时释放，Timing 维加分，Fit 维视行业而定。
- **Hook**：「恭喜 B 轮——扩张期的付款体量会很快碰到银行电汇的天花板，我们帮出海团队把供应商付款压到 T+1。」

## S2 招聘信号

- **Definition**：招聘信息显示正在扩充财务、采购、合规或海外运营岗位。
- **Why-predicts-fit**：财务/采购扩编意味着付款与对账工作量即将上升，是工具需求的前置指标；运营扩编提示新市场动作，Access 维加分。
- **Hook**：「看到贵司在招财务运营——新同事入职第一周就接手对账的话，我们的自动化对账能让他少熬一个月。」

## S3 市场扩张信号

- **Definition**：官网/领英出现新海外主体、新市场职位或当地语言站点。
- **Why-predicts-fit**：跨境主体带出多币种付款与多账套权限需求，直接命中平台核心场景，Fit 与 Intent 双维加分。
- **Hook**：「新主体落地第一件事是开本地账户和付本地供应商——这两件事我们可以同周搞定。」

## S4 工具栈替换信号

- **Definition**：现有付款工具为传统银行网银（无 API），或公开信息显示在选型新财务系统。
- **Why-predicts-fit**：网银无 API 意味着对账全人工——痛点已被验证存在，只差一个触发事件；选型期是 Intent 最强窗口。
- **Hook**：「不换银行——我们在银行账户之上加一层 API 和自动对账，安全不降级。」

## S5 行业匹配信号

- **Definition**：行业属于外贸、跨境服务、连锁零售或出海 SaaS。
- **Why-predicts-fit**：四类行业跨境付款频次与币种复杂度天然高，历史成单率显著高于均值，Fit 维基础分。
- **Hook**：「你们同行（案例名）上季度把到账时间从 3 天压到 1 天，供应商条款都重新谈过一轮。」

## 评分卡维度映射

| 维度 | 主信号 | 辅信号 |
|---|---|---|
| Fit（0-25） | S5 行业匹配 | S3 市场扩张 |
| Timing（0-25） | S1 融资 | S4 工具栈替换 |
| Access（0-25） | S2 招聘（触达财务/采购决策人） | — |
| Intent（0-25） | S4 工具栈替换 | S3 市场扩张 |

- 每维得分必须引用「用户提供事实」或「本信号库条目 + 来源编号」；无证据维度记 0 并标注「资料未覆盖, 需人工补充」。
- 命中 icp-targeting「不接的行业」红线时，评分卡作废，tier 直接判「不追」。
