# ICP 分层与线索路由规则

> 仅 sales 及以上角色可见。本页定义我们优先打哪类企业，以及线索怎么分配。

## 一、三层客户画像

- **SMB**：年营收 < 500 万 SGD，10-50 人；单币种为主，月付款笔数少，价格敏感。
- **中端市场**：年营收 500 万 - 5,000 万 SGD，50-300 人；供应商多、币种多，需要分级授权与自动对账。
- **企业客户**：年营收 > 5,000 万 SGD，300 人以上；多实体、多账套，要求 API 集成与 SLA。

## 二、分层路由规则

- **自助通道**：SMB 且月付款笔数 < 50 → 官网自助注册，不分配人工跟进。
- **SDR 跟进**：中端市场，或 SMB 但月付款笔数 50-200 → SDR 电话初筛后转 AE。
- **AE 直跟**：企业客户，或任意层级但月跨境付款笔数 > 200 → 直接分配给 AE，**24 小时内首触**。
- 路由冲突时以「年营收 + 月付款笔数」双指标取高者为准，不允许人工抢占路由结果。
- 路由结果写入 CRM 字段，SDR 不得擅自修改，异议走销售运营申诉。

## 三、分层打法差异

- SMB：内容驱动 + 自助转化，主打「10 分钟开卡、免月费试用」，压缩人力投入。
- 中端市场：SDR 约会议 + AE 场景化演示，主打自动对账与多币种钱包。
- 企业客户：多干系人推进（财务、IT、合规），主打 API 集成、SLA 与专属客户经理。

## 四、优先级信号（加分项）

- 近期完成新一轮融资（B 轮及以上），扩张意愿强。
- 招聘信息显示正在扩充财务或采购团队。
- 官网或领英显示新开海外主体、新市场。
- 现有工具为传统银行网银，无 API 能力。
- 行业属外贸、跨境服务、连锁零售、出海 SaaS。

## 五、不接的行业

- 虚拟货币、线上赌博、成人内容一律不接。
- 股东结构不透明、无法完成 KYC 的企业转合规评估，评估期间不得报价。
- 命中制裁名单的地区与主体，立即终止并上报合规。
