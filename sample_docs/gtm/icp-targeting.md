# ICP 分层与线索路由规则

> 仅 sales 及以上角色可见。本页定义我们优先打哪类企业，以及线索怎么分配。

## 一、三层客户画像

- **SMB**：年营收 < 500 万 SGD，10-50 人；单币种为主，月付款笔数少，价格敏感。
- **中端市场**：年营收 500 万 - 5,000 万 SGD，50-300 人；供应商多、币种多，需要分级授权与自动对账。
- **企业客户**：年营收 > 5,000 万 SGD，300 人以上；多实体、多账套，要求 API 集成与 SLA。

## 二、分层路由规则

- **自助通道**：SMB 且月付款笔数 < 50 → 官网自助注册，不分配人工跟进。
- **SDR 跟进**：中端市场，或 SMB 但月付款笔数 50-200 → SDR 电话初筛后转 AE。
- **AE 直跟**：企业客户，或任意层级但月跨境付款笔数 > 200 → 直接分配给 AE，**24 小时内首触**。
- 路由冲突时以「年营收 + 月付款笔数」双指标取高者为准，不允许人工抢占路由结果。
- 路由结果写入 CRM 字段，SDR 不得擅自修改，异议走销售运营申诉。

## 三、分层打法差异

- SMB：内容驱动 + 自助转化，主打「10 分钟开卡、免月费试用」，压缩人力投入。
- 中端市场：SDR 约会议 + AE 场景化演示，主打自动对账与多币种钱包。
- 企业客户：多干系人推进（财务、IT、合规），主打 API 集成、SLA 与专属客户经理。

## 四、优先级信号（加分项）

- 近期完成新一轮融资（B 轮及以上），扩张意愿强。
- 招聘信息显示正在扩充财务或采购团队。
- 官网或领英显示新开海外主体、新市场。
- 现有工具为传统银行网银，无 API 能力。
- 行业属外贸、跨境服务、连锁零售、出海 SaaS。

## 五、不接的行业

- 虚拟货币、线上赌博、成人内容一律不接。
- 股东结构不透明、无法完成 KYC 的企业转合规评估，评估期间不得报价。
- 命中制裁名单的地区与主体，立即终止并上报合规。

## 六、信号评分卡规则（Fit / Timing / Access / Intent）

评分口径：四维各 0-25 分，总分 100。只依据「用户提供的公司事实」与本节锚点打分，缺事实的维度记 0 并标「需人工补充」。

- **Fit（行业与规模匹配度）**：行业在 ICP 画像内且规模命中第一节分层锚点 → 20-25；行业匹配但规模未达标 → 10-15；行业不匹配 → 0-5。
- **Timing（时机信号）**：B 轮及以上融资 → 20-25；无融资但拓新市场或新开主体 → 15-20；无时机信号 → 0-5。
- **Access（触达路径）**：官网自助入口、内推关系、高管可直接联系，每命中一项 +8；无触达路径 → 0。
- **Intent（意图信号）**：扩编财务/采购团队中 → 15-25；官网搜索或内容下载 → 10-15；无意图证据 → 0。

tier 映射与响应 SLA：

- **Hot 80-100**：AE 2 小时内响应
- **Warm 60-79**：SDR 24 小时内首触
- **Cold 40-59**：进入培育序列或 PARK
- **低于 40 或命中红线**：不追

## 七、不追清单（anti-ICP disqualifiers）与 PARK 层

红线（命中即不追，无例外）：

- MAS/OFAC 制裁名单主体或关联方（同第五节，立即终止并上报合规）
- 无实体经营的空壳主体
- 虚拟货币、线上赌博、成人内容等高风险行业（同第五节）
- 与竞品签有 12 个月以上锁死合约

PARK 层（暂缓不追，季度重评）：

- 预算未批
- 决策层换岗
- 组织重组中

命中红线时，简报的路由建议必须输出「不追」并引用本节；PARK 层进入季度重评队列。

## 八、目标行业速查表

| 行业 | 核心痛点 | 关键决策人 | 切入话术 |
|------|---------|-----------|---------|
| 外贸出口 | 汇率损耗不可见、多币种对账耗时 | 财务总监 | 免费换汇成本测算，对比现有银行报价 |
| 跨境服务（物流/咨询/软件外包） | 回款周期长、币种错配 | 合伙人或运营负责人 | 回款周期缩短 40% 的同规模案例 |
| 连锁零售 | 门店采购失控、店长垫付 | 区域运营总监 | 虚拟卡按门店设额度，超限自动拒付 |
| 出海 SaaS | 订阅回款慢、多主体收款 | CFO | API 自动出款 + 多账套权限 |
| 跨境电商卖家 | 多平台多币种分散、对账混乱 | 创始人或财务 | 统一钱包 + 批量付款，一个后台看全部 |
